第一章 · 功能总览

功能总览

所有命令都在游戏内聊天框输入。本服务器安装了「一键解锁」插件，提供以下玩家命令：

命令作用
/一键解锁一键学会服务器开放分组内的全部印痕（制作图纸立刻全点亮）
符号约定：命令格式里的 [方括号] 表示可选参数，只是标注——实际输入时不要输入方括号。本插件的命令没有参数，教程里的示例都是能直接照抄的真实输入。
命令名以服务器公告为准：服主可以改命令文本，如果 /一键解锁 没反应，先在群里或公告里确认本服的命令写法。

第二章 · 玩法说明

怎么用（从头到尾三步）

  1. 打开聊天框

    按平时发消息的方式打开聊天输入框 → 准备输入命令。

  2. 输入命令并发送

    输入 /一键解锁 并发送 → 服务器立即处理，无需等待读条。

  3. 查看完成通知

    屏幕中央弹出解锁完成通知（默认青色，显示本次解锁数量）→ 打开印痕 / 制作界面，新图纸已经全部点亮。

已学会的印痕不会重复给，所以这条命令可以放心重复使用——它只会补上你还没学的那部分。
死亡、观战等状态下命令没有反应，复活回到角色后再用。部分印痕分组（如泰克科技）是否开放由服主决定，没开就不会包含在内。
第三章 · 命令详解

/一键解锁

作用：一键学会服务器开放分组内的全部印痕。新号开荒不用再一个个点印痕，输入一次全搞定。

/一键解锁
参数必填说明
（无参数）—这条命令不需要任何参数，原样输入即可

示例：/一键解锁（原样输入：立即解锁，屏幕弹出完成通知）　/kjjs（如果本服把命令改成了 /kjjs，就输入这个，效果完全一样）

反馈：成功时屏幕中央弹出解锁完成通知，默认文案「一键解锁完成, 本次解锁: N 个印痕」、青色、约 5 秒（具体样式由服主配置，可能被修改或关闭）。如果通知里 N 是 0，说明该学的你之前都学会了。死亡、观战状态下没有任何反应。管理员隐藏的特殊印痕不会通过这条命令发放。

命令区分大小写，输入时注意和公告里的写法保持一致。
第四章 · 常见问题

常见问题

输入 /一键解锁 没反应？
先试这个：① 确认命令写法（本服可能改过命令名，看服务器公告）；② 确认自己不在死亡 / 观战状态；③ 注意大小写要和公告一致。还不行就联系服主。
为什么有些图纸没解锁？
先试这个：开放范围由服主按分组控制（比如泰克科技可能没开）；另外你已经学会的、管理员隐藏的图纸都不会重复出现。想确认某个分组开没开，问服主。
这条命令能用几次？
先试这个：随便用。已经学会的印痕会自动跳过，重复使用只补新的，不会出错也不会重复计数。
解锁后在哪里看效果？
先试这个：打开印痕 / 制作界面查看，新学会的图纸已经点亮，可以直接制作对应物品。
通知里「本次解锁: 0 个」是什么意思？
先试这个：说明开放分组里的印痕你之前已经全部学会了，这次没有新的可补——不是出错了。
