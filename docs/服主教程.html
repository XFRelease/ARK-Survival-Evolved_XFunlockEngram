第一章 · 软件总览

软件总览

「一键解锁」是方舟生存进化（ARK: Survival Evolved）服务端插件：玩家在聊天框输入一条命令，即可学会服务器开放分组内的全部印痕，开放范围由你在配置里按分组精确控制。

🗝️

一键解锁印痕

玩家一条聊天命令，配置开启分组内的印痕全部点亮，完成后屏幕显示本次解锁数量。

🗂️

九大分组开关

按孤岛、焦土、畸变、灭绝、创世、泰克等分组逐个控制开放范围，默认开启 7 组。

✏️

命令随心改名

两个聊天命令的文本都在配置里自定义，换服务器风格不用改代码。

🔄

三通道热重载

聊天、控制台、RCON 三条途径重载配置，分组开关、通知气泡与控制台编码改完即生效。

🖥️

控制台编码自适应

ArkApi 3.54（GBK）与 3.55（UTF-8）服务器的中文日志均不乱码，默认自动探测。

🪶

轻量零依赖

无数据库、无授权验证、无额外运行库，三个文件放进插件目录即可使用。

第三章 · 部署安装

部署安装

  1. 确认服务器已安装 ArkApi

    服务器能通过 ArkApi 加载其他插件即已安装；从未安装过请先完成 ArkApi 部署 → 再进行下一步。

  2. 关闭服务器

    停止方舟服务器进程 → 确认控制台已退出 → 下一步复制文件。

  3. 复制插件文件

    把 XFunlockEngram.dll、PluginInfo.json、config.json 三个文件复制到 <服务器目录>\ShooterGame\Binaries\Win64\ArkApi\Plugins\XFunlockEngram\ → 目录不存在时手动新建，目录名必须为 XFunlockEngram → 复制完成进入下一步。

  4. 按需修改配置

    用文本编辑器打开目录里的 config.json → 按第四、五章说明调整分组开关与命令文本 → 保存为 UTF-8 编码。

  5. 启动服务器

    启动方舟服务器 → 控制台出现横幅「先锋.一键解锁(1.0) 先锋方舟服主群:138535385 作者QQ:711919」→ 说明插件加载成功。

  6. 进服验证

    进入游戏在聊天框输入 /一键解锁 → 屏幕中央出现青色通知「一键解锁完成, 本次解锁: N 个印痕」→ 部署完成。

config.json 必须与 DLL 放在同一目录且格式正确：文件缺失或 JSON 语法错误都会导致插件加载失败（控制台报 Can't open config.json 或解析错误）。插件不会自动生成配置文件，请随包部署。
第四章 · 配置详解

配置文件说明

所有配置集中在一个文件：<服务器目录>\ShooterGame\Binaries\Win64\ArkApi\Plugins\XFunlockEngram\config.json。完整结构如下：

{
  "ConsoleEncoding": "auto",
  "ChatCommand": {
    "PlayerCommands": {
      "UnlockEngrams": "/一键解锁"
    },
    "AdminCommands": {
      "UpdateSettings": "/XFunlockEngramReload"
    }
  },
  "Notification": {
    "UnlockComplete": {
      "Text": "一键解锁完成, 本次解锁: {} 个印痕",
      "Scale": 2.0,
      "Time": 5,
      "Color": "0,255,255,100"
    }
  },
  "UnlockEngram": {
    "ARK_PRIME": true,
    "ARK_SCORCHEDEARTH": true,
    "ARK_TEK": false,
    "ARK_UNLEARNED": false,
    "ARK_ABERRATION": true,
    "ARK_EXTINCTION": true,
    "ARK_GENESIS": true,
    "ARK_GEN2": true,
    "ARK_AQUATICA": true
  }
}
JSON 里逗号、引号一个都不能少。建议用带 JSON 校验的编辑器（如 VS Code、Notepad++）修改；改前先备份一份能用的配置。

第四章 · 配置详解

ConsoleEncoding 控制台编码

什么意思：控制插件往服务器控制台输出中文时的编码。ArkApi 3.54 的服务器控制台是 GBK、3.55 是 UTF-8，设错会出现中文乱码。

兜底值：auto（未配置时的默认值，按控制台代码页自动探测；填了不认识的值或类型不对也会回落 auto，并在控制台黄字提醒）

{
  "ConsoleEncoding": "auto"
}

怎么修改：取值大小写不敏感，可选：auto 自动探测（推荐，两类服务器通用）；gbk 或 ansi 强制 GBK（3.54 老版本服务器乱码时用）；utf8 或 utf-8 强制 UTF-8（3.55 服务器）。改完后执行任一重载命令即热生效，无需重启。

第四章 · 配置详解

ChatCommand 命令改名

什么意思：定义两个聊天命令的触发文本。命令文本就是玩家在聊天框输入的完整第一段（含前导 /），改这里等于换命令名。

兜底值：缺失即不注册（键缺失或不是字符串时，对应命令不注册，启动时控制台黄字提示「未配置, 跳过注册」）

{
  "ChatCommand": {
    "PlayerCommands": {
      "UnlockEngrams": "/一键解锁"
    },
    "AdminCommands": {
      "UpdateSettings": "/XFunlockEngramReload"
    }
  }
}

怎么修改：引号内改成你想要的命令文本即可，例如 "/kjjs"、"/解锁印痕"。PlayerCommands 下的命令所有玩家可用，AdminCommands 下的仅管理员可用。键名 UnlockEngrams、UpdateSettings 是插件识别用的，不要改。

命令文本只在插件加载时注册：改名后需要重启服务器才生效（分组开关等其他配置走重载命令即时生效）。命令文本必须与玩家输入完全一致，大小写敏感。
第四章 · 配置详解

UnlockEngram 印痕分组开关

什么意思：控制「一键解锁」开放哪些分组的印痕。玩家执行命令时，只有开关为 true 的分组里的印痕会被解锁。

兜底值：缺失或非布尔 = false（每组键缺失、或值不是 true/false，一律按关闭处理）

{
  "UnlockEngram": {
    "ARK_PRIME": true,
    "ARK_SCORCHEDEARTH": true,
    "ARK_TEK": false,
    "ARK_UNLEARNED": false,
    "ARK_ABERRATION": true,
    "ARK_EXTINCTION": true,
    "ARK_GENESIS": true,
    "ARK_GEN2": true,
    "ARK_AQUATICA": true
  }
}

怎么修改：把要开放的分组改为 true，要关闭的改为 false，保存后执行重载命令即生效。各组含义：

分组键默认值含义与效果
ARK_PRIMEtrue孤岛 / 主世界印痕
ARK_SCORCHEDEARTHtrue焦土地图印痕
ARK_TEKfalse泰克科技印痕（默认不随一键解锁发放）
ARK_UNLEARNEDfalse未学习类（Unlearned）印痕（默认不发放）
ARK_ABERRATIONtrue畸变地图印痕
ARK_EXTINCTIONtrue灭绝地图印痕
ARK_GENESIStrue创世 1 印痕
ARK_GEN2true创世 2 印痕
ARK_AQUATICAtrueAquatica（水世界）印痕；游戏内该分组数值为 130，插件按此数值识别
两道安全闸门：玩家已经学会的印痕不会重复发放；被服务器隐藏的印痕（隐藏判定）永远不会被解锁——管理员隐藏的测试物品不会借此流出。
第四章 · 配置详解

Notification 通知气泡

什么意思：控制玩家执行 /一键解锁 后弹出的屏幕通知气泡——文案、文字大小、显示时长、颜色全部可配。配置按消息键分层：Notification.<消息键>.Text / Scale / Time / Color，当前唯一消息键 UnlockComplete（解锁完成气泡）；以后插件新增气泡会各占一个新的下级键，互不影响。

兜底值：缺失 / 类型不对 = 内置默认（文案为「一键解锁完成, 本次解锁: {} 个印痕」、大小 2.0、时长 5 秒、颜色 0,255,255,100 青色半透明；数值低于下限同样回落默认）

{
  "Notification": {
    "UnlockComplete": {
      "Text": "一键解锁完成, 本次解锁: {} 个印痕",
      "Scale": 2.0,
      "Time": 5,
      "Color": "0,255,255,100"
    }
  }
}

怎么修改：

键取值说明
Text任意文本气泡文案；文本中第一个 {} 会被替换为本次解锁数量，不含 {} 则原样显示；留空字符串 = 关闭该条通知（玩家执行命令不再弹气泡）
Scale数字，下限 0.1文字大小，默认 2.0；想更醒目可改 3.0 等
Time数字（秒），下限 0.5显示时长，默认 5
Color"R,G,B,A" 字符串四段 0–255 整数，容许空格；例如白色 "255,255,255,100"、金色 "255,200,0,100"；格式不对回落青色
通知配置实时读取：修改后执行重载命令即生效，无需重启。文本与颜色改动建议进服实际弹一次确认效果。

第五章 · 命令用法详解

/一键解锁（玩家命令）

作用：给执行者本人发放服务器开放分组内的全部印痕。开荒、新手教学、节日福利场景使用。

/一键解锁
参数必填缺省值说明
（无参数）——本命令不接受任何参数

示例：/一键解锁（裸命令：立即解锁所有开放分组印痕，屏幕弹出完成通知）　/kjjs（服主把命令改名为 /kjjs 后的等效输入）

反馈：成功时屏幕中央弹出解锁完成通知气泡，默认青色、文案「一键解锁完成, 本次解锁: N 个印痕」、约 5 秒——文案、大小、时长、颜色均可配置（见 Notification 小节，留空文案可关闭）。测试版插件还会在控制台输出统计（解锁 / 隐藏 / 跳过分组 / 已解锁数量及分组明细），正式版仅保留玩家通知。玩家处于死亡、观战等没有角色实体的状态时命令无反应。解锁走服务端强制解锁方式，已学会的与被隐藏的印痕自动跳过。

第五章 · 命令用法详解

/XFunlockEngramReload（管理员命令）

作用：不重启服务器重新载入 config.json。改完分组开关、通知气泡、控制台编码后用它即时生效。默认命令带插件英文名前缀，避免与其他插件的重载命令撞名失灵。

/XFunlockEngramReload
参数必填缺省值说明
（无参数）——本命令不接受任何参数

示例：/XFunlockEngramReload（裸命令：重载配置并聊天回复结果）　/reload（服主把命令改名为 /reload 后的等效输入）

反馈：仅服务器管理员可用（按管理员身份判定），非管理员执行无任何提示。成功时聊天回复「一键解锁: 配置已重新载入」；失败时聊天回复「一键解锁: 配置重载失败: 」并附具体原因（通常是 JSON 语法错误），同时控制台红字输出同一信息。注意：命令文本本身改名后需重启服务器（见第四章）。

第五章 · 命令用法详解

XFunlockEngram.Reload（控制台 / RCON 命令）

作用：与 /XFunlockEngramReload 等效，供不在游戏内时使用（服务器控制台、RCON 工具、管理面板）。

XFunlockEngram.Reload
参数必填缺省值说明
（无参数）——本命令不接受任何参数

示例：XFunlockEngram.Reload（在服务器控制台或 RCON 直接输入：重载配置）　cheat XFunlockEngram.Reload（在游戏内管理员控制台输入的等效写法）

反馈：成功时控制台 / RCON 返回「Reloaded config」；失败时返回「Failed to reload config」并在服务器日志记录具体错误。重载同时会重新应用 ConsoleEncoding 编码设置。

第六章 · 常见问题

常见问题

玩家说输入 /一键解锁 没反应？
按顺序排查：① 命令是否被改名（看 ChatCommand.PlayerCommands.UnlockEngrams）；② 启动时控制台是否有「未配置, 跳过注册」黄字——有则说明该键缺失或不是字符串；③ 玩家是否处于死亡 / 观战状态（此时静默无反应，复活后再试）。
改了配置为什么没生效？
分组开关、通知气泡、控制台编码改完要执行 /XFunlockEngramReload 或 XFunlockEngram.Reload 才生效；聊天命令文本改名必须重启服务器（命令只在插件加载时注册）。
泰克（TEK）印痕为什么解不了？
ARK_TEK 与 ARK_UNLEARNED 两个分组默认关闭。把对应键改为 true，执行重载命令后再让玩家使用命令即可。
/XFunlockEngramReload 提示失败怎么办？
聊天回复里会带具体原因，绝大多数是 JSON 语法错误：多逗号、少逗号、中文引号、漏引号。用带 JSON 校验的编辑器检查后保存，再执行一次重载即可恢复。
控制台中文乱码？
把 ConsoleEncoding 设为 auto（默认，自动适配 3.54 / 3.55）；仍乱码时老版本服务器强制 gbk、新版本强制 utf8，改完执行重载命令即时生效。
想临时停用插件？
关闭服务器后把 XFunlockEngram.dll 改名为 XFunlockEngram.dll.arkapi（ArkApi 的停用后缀）或移出插件目录，重启服务器即不加载；恢复名字再重启即可启用。
