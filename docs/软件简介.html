软件简介

一键解锁 一条命令 学会所有印痕

玩家聊天输入 /一键解锁，开放分组的印痕一次全部点亮——你勾选分组，它替你把新手教学自动化。

01 · 软件定位

软件定位

新玩家进服第一件事就是点印痕：几十上百个图纸一个个点过去，点错还要洗点；服主要做「新手送全套印痕」活动，只能手动发物品或改等级曲线，费时还容易出错。「一键解锁」就是冲着这两头难受来的。

它是方舟生存进化服务端插件（ArkApi 平台）：玩家在聊天框输入 /一键解锁，服务器开放分组内的印痕立刻全部学会；开放哪些分组由你在配置文件里勾选。一次部署，长期自动营业——你的新手引导成本，从「逐个教」降到「一句话」。

03 · 重点功能

一键解锁印痕 核心

什么功能：玩家在聊天框输入 /一键解锁，服务器立即为他解锁所有开放分组内、未隐藏且未学会的印痕，完成时屏幕中央弹出解锁通知——文案、颜色、大小、时长全部可在配置里自定义（按消息独立设置，留空文案即关闭）。

什么作用：新号开荒直接跳过逐个点印痕的苦差事；想造什么立刻能造，开局体验拉满。

给你的好处：没有它，你要么眼看玩家被印痕系统劝退，要么搞等级曲线、手动发奖这些重活，还得盯着别发漏发多。有了它，教学这件事一行命令自动搞定——玩家自助、即时生效、数量反馈清清楚楚；你睡觉，它营业。命令可以重复使用（已学会的自动跳过），逢年过节当福利发也不怕刷出问题。

03 · 重点功能

九大分组开关 精细控场

什么功能：配置文件里九个分组开关（孤岛 / 焦土 / 泰克 / 未学习 / 畸变 / 灭绝 / 创世 1 / 创世 2 / Aquatica 水世界），逐组决定哪些印痕参与一键解锁。

什么作用：想做「本服禁泰克一键」？把 ARK_TEK 设为 false 就行；想开放全图科技？全部设 true。科技节奏完全在你手里。

给你的好处：不用它，控制科技进度要靠改印痕配置、调等级曲线这些又深又险的活，改错一处全服翻车。用它，改一个 true / false、发一条重载命令就完成调整——活动周开放泰克、活动结束再关上，前后一分钟。再加上「隐藏印痕永不解锁」的内置闸门，你藏起来的测试物品永远安全。

03 · 重点功能

三通道热重载 免重启

什么功能：游戏内管理员命令 /XFunlockEngramReload、服务器控制台与 RCON 命令 XFunlockEngram.Reload，三条路都能不重启重新载入配置（默认命令带插件英文名前缀，多插件共存也不会撞名失灵）。

什么作用：改完分组开关、控制台编码，一条命令立即生效；重载成功失败都有明确反馈，失败原因直接告诉你（通常是 JSON 写错）。

给你的好处：不用它，每次调配置都要停服重启，在线玩家全部掉线。用它，白天在线高峰期照样调参数——玩家甚至察觉不到你在动配置。重载失败也只影响新配置生效，不会带崩服务器。
